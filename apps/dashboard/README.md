# Утро. Аналитика продаж сети кофеен

Концепт для портфолио: дашборд продаж для владельца вымышленной сети из пяти кофеен в Москве (Патриаршие, Чистые пруды, Хлебозавод, Сити, Таганка). Компания, цены и данные вымышлены.

Статичная страница на HTML, CSS и чистом JavaScript. Без сборки, фреймворков и библиотек графиков: все графики нарисованы вручную в SVG. Открывается двойным кликом по `index.html`.

## Возможности

- Период: 7, 30, 90 дней или свой диапазон через два поля дат (с проверкой: обе даты, порядок, границы истории).
- Фильтр точек чипами с множественным выбором, кнопка «Все точки».
- Сравнение с предыдущим периодом такой же длины (переключатель).
- Экспорт текущей выборки в CSV (по дням и точкам, разделитель `;`, UTF-8 с BOM для Excel).
- Светлая и тёмная тема: по настройке системы и переключателем в шапке, выбор сохраняется.
- Фильтры тоже сохраняются между визитами (localStorage; без хранилища всё работает, просто не запоминается).

Экран:

1. Ведущий показатель: выручка за период крупно, изменение к прошлому периоду (стрелка, знак и слова, не только цвет) и спарклайн.
2. Три второстепенных: чеки, средний чек, выручка на точку в день.
3. Выручка по дням (от 90 дней по неделям, средняя выручка в день). Пунктир: прошлый период. Режим «По точкам» рисует линию каждой точки. Метки непогоды, подпись максимума, тултип по наведению и с клавиатуры (стрелки, Home, End, PageUp, PageDown, Escape).
4. Выручка по точкам: отсортированные горизонтальные полосы с суммой, долей и изменением.
5. Тепловая карта «день недели x час» со шкалой и тултипом, управление стрелками.
6. Позиции меню: таблица с сортировкой по любому столбцу (`aria-sort`), доля мини-полосами, изменение к прошлому периоду.

Под каждым графиком строка вывода, вычисленная из данных. У каждого графика есть `role="img"` с выводом в `aria-label` и кнопка «Таблица», которая показывает те же данные таблицей.

Особые состояния: не выбрано ни одной точки; выбрана только Таганка (открылась 60 дней назад) и период целиком до её открытия; точка открылась внутри периода (уведомление); прошлый период выходит за начало истории.

## Структура

```
index.html      разметка, спрайт иконок lucide
css/style.css   токены (примитивы, семантика, тёмная тема) и компоненты
js/data.js      генератор данных: 180 дней по часам, по точкам и позициям
js/app.js       агрегация, графики, фильтры, экспорт
```

## Как править данные

Данные не лежат готовым массивом, а генерируются при загрузке в `js/data.js` детерминированно: генератор случайных чисел засевается календарной датой и номером точки, поэтому одна и та же дата всегда даёт одни и те же цифры. История всегда заканчивается вчерашним днём.

- `STORES`: название, базовый поток чеков в будний день (`base`), коэффициент выходных (`weekend`), профиль часов (`profile: 'city'` для офисного района) и `openedDaysAgo` для новой точки.
- `ITEMS`: позиции меню, цена в рублях и веса по частям дня (утро, обед, вечер). `growth` задаёт растущий тренд позиции, `summer` делает её сезонной.
- `WEEKDAY`, `WEEKEND`, `CITY_WEEKDAY`: профили часов.
- Погодные провалы выбираются по хешу даты, их глубина в поле `dip`.

Чтобы подключить настоящие данные, достаточно заполнить `window.APP_DATA` в том же формате: массивы `rev`, `checks` (по точке, дню и часу) и `itemQty` (по точке, дню и позиции).

## Цвета

Палитра серий для точек взята из проверенной категориальной палитры и прогнана валидатором (яркость, насыщенность, различимость при протанопии и дейтеранопии, контраст с фоном) для обеих тем. Цвет закреплён за точкой и не меняется при фильтрации. Тепловая карта использует одну фиолетовую последовательную шкалу. Основной цвет интерфейса тоже фиолетовый, поэтому общая выручка не путается ни с одной точкой.

## Публикация на GitHub Pages

1. Создайте репозиторий и положите в него содержимое папки (`index.html` в корне).
2. Settings, Pages, Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Шрифт Inter подключается из Google Fonts; без сети страница использует системный шрифт.
