# Сталь: онлайн-запись в барбершоп и панель администратора

Концепт для портфолио. Компания «Сталь», мастера, цены и данные вымышлены, фотографии не используются.

Одностраничное приложение на чистом HTML, CSS и JavaScript. Работает без сервера и без сборки: достаточно открыть `index.html` двойным кликом. Все записи хранятся в `localStorage` браузера; если хранилище недоступно (приватный режим, запрет сайта), приложение продолжает работать в памяти до перезагрузки.

## Возможности

### Клиентская запись (`#/`)

Визард из четырёх шагов с индикатором прогресса и кнопкой «Назад»:

1. **Услуги.** Прайс из семи услуг, можно выбрать несколько; сумма и общая длительность пересчитываются сразу. Комплекс «Стрижка + борода» автоматически заменяет отдельные стрижку и бороду.
2. **Мастер.** Четыре мастера с монограммами, стажем, специализацией, рейтингом и выходным днём. Топ-мастер выделен, его цена выше на 20%. Вариант «Любой свободный мастер» подбирает наименее загруженного мастера на выбранное время.
3. **Дата и время.** Лента на 14 дней (выходные и выходной мастера помечены, у каждого дня видно число свободных окон). Сетка слотов по 15 минут с 10:00 до 21:00: слот недоступен, если пересекается с существующей записью с учётом длительности выбранных услуг, уже прошёл или услуги не успевают закончиться до закрытия. Если свободных окон нет, показывается пустое состояние с кнопкой ближайшего свободного дня.
4. **Контакты.** Имя, телефон с маской `+7 (XXX) XXX-XX-XX` и проверкой 11 цифр, комментарий, напоминание. Итоговая карточка с услугами, мастером, временем, длительностью и суммой.

После записи: экран подтверждения с номером записи, кнопки «Добавить в календарь» (скачивает `.ics`, созданный через `Blob`) и «Отменить запись» (с подтверждением). Раздел «Мои записи» (`#/my`) показывает записи, сделанные в этом браузере, с отменой.

### Панель администратора (`#/admin`)

Вход через ссылку «Вход для администратора» в подвале. Настоящей авторизации нет: экран демо-режима честно об этом сообщает, пароль не нужен.

- **День** (`#/admin/day/ГГГГ-ММ-ДД`): KPI за день (выручка крупно, записи, загрузка мастеров, средний чек), расписание с колонками мастеров, блоками записей высотой по длительности, статусами «подтверждена / пришёл / не пришёл» (цвет + иконка + текст), линия текущего времени, переключение дня стрелками и выбором даты. На телефоне колонки прокручиваются по горизонтали с подсказкой и затемнением края.
- **Боковая панель записи**: детали, смена статуса, перенос на другое время, дату или мастера с проверкой пересечений, отмена с подтверждением. Фокус удерживается внутри панели, Escape закрывает, фокус возвращается на запись.
- **Быстрое создание**: клик по пустому месту в колонке мастера открывает форму с уже подставленными мастером и временем; кнопка «Новая запись» делает то же с клавиатуры.
- **Неделя** (`#/admin/week/ГГГГ-ММ-ДД`): выручка и загрузка по дням на SVG-графике (факт и план по записям различаются штриховкой) и таблица-сводка.
- **Сбросить демо-данные**: удаляет все записи и заново генерирует демо-расписание.

При первом запуске генерируются правдоподобные записи на 6 дней назад и 7 дней вперёд с загрузкой 55-80%, плюс редкие ранние записи ещё на неделю вперёд. Генератор детерминированный (фиксированный seed): при одной и той же текущей дате расписание всегда одинаковое. Все даты считаются в локальном времени пользователя.

## Структура

```
index.html        разметка, SVG-спрайт иконок (lucide), диалоги
css/style.css     токены (примитивы -> семантика), светлая и тёмная тема, компоненты
js/data.js        данные: адрес, часы, услуги, мастера, имена для демо-записей
js/store.js       хранилище, работа с датами, расчёт свободных окон, демо-генератор
js/ui.js          общие помощники: тосты, диалог подтверждения, маска телефона, .ics
js/client.js      клиентский визард, подтверждение, «Мои записи»
js/admin.js       панель администратора: день, боковая панель, неделя
js/app.js         hash-роутер
```

## Как редактировать данные

Всё в `js/data.js`:

- `shop`: адрес, телефон, часы работы (`open` и `close` в минутах от полуночи: 600 = 10:00), шаг сетки, глубина записи в днях, надбавка топ-мастера.
- `services`: название, описание, длительность в минутах, цена.
- `masters`: имя, инициалы для монограммы, признак `top`, стаж, специализация, рейтинг, выходные (`daysOff`: 0 = воскресенье ... 6 = суббота).

После изменения услуг или мастеров нажмите в админке «Сбросить демо-данные», чтобы демо-расписание собралось заново. Цвета, шрифты и отступы меняются в блоке токенов в начале `css/style.css`; тёмная тема переопределяет только семантические токены.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое папки (так, чтобы `index.html` лежал в корне или в папке `docs/`).
2. В репозитории откройте Settings -> Pages, в Source выберите ветку `main` и папку `/ (root)` или `/docs`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`. Маршруты работают через `#`, поэтому дополнительные настройки сервера не нужны.

Шрифты Playfair Display и Golos Text подключаются из Google Fonts; без сети используется системный шрифт.
