# Зерно и Пламя: интернет-магазин обжарщика кофе

Концепт для портфолио. Одностраничный магазин небольшой обжарочной из Санкт-Петербурга: каталог с фильтрами, карточка товара, корзина, оформление заказа по шагам, история заказов и избранное. Компания, цены и данные вымышлены, фото с лицензией CC0, оплата тестовая.

Работает без сервера и без сборки: достаточно открыть `index.html` двойным щелчком.

## Возможности

- **Каталог** (`#/`): история обжарочной, фильтры по категории, обработке, обжарке и цене, поиск по названию, стране и вкусовым дескрипторам, сортировка, счётчик результатов, пустое состояние со сбросом. Все фильтры записываются в адрес страницы, ссылкой можно поделиться. Первый товар в выдаче показан крупнее, с описанием и вкусовым профилем.
- **Карточка товара** (`#/product/<slug>`): галерея (упаковка, этикетка с данными лота, фото), вкусовой профиль на шкалах, выбор веса и помола, количество, добавление в корзину с состоянием загрузки и подтверждением, избранное, блок «С этим берут».
- **Остатки**: у товаров с бейджем «Мало осталось» количество в корзине ограничено складом, это видно на карточке, в корзине и в каталоге.
- **Корзина**: выезжающая панель на нативном `<dialog>` (фокус внутри, Escape, возврат фокуса), изменение количества, удаление с возможностью вернуть, прогресс до бесплатной доставки от 3000 ₽, промокод `ZERNO10` (скидка 10%).
- **Оформление** (`#/checkout`): контакты, доставка (курьер по СПб, самовывоз, пункт выдачи по России, у каждого способа свои поля), оплата (тестовая форма карты с маской и проверкой по алгоритму Луна или оплата при получении), подтверждение. Валидация на каждом шаге, сводка заказа сбоку.
- **Заказ** (`#/order/<номер>`), **история** (`#/orders`, повтор заказа, удаление истории с подтверждением), **избранное** (`#/favorites`).
- Корзина, промокод, избранное, заказы и черновик оформления хранятся в `localStorage`. Данные карты не сохраняются никогда. Если хранилище недоступно, магазин работает из памяти.
- Светлая и тёмная тема по настройке системы, адаптив от 280 px, управление с клавиатуры, `prefers-reduced-motion`.

## Структура

```
index.html      каркас: шапка, подвал, диалоги (корзина, фильтры, подтверждение), SVG-спрайт иконок
css/style.css   токены (примитивы -> семантика), тёмная тема, компоненты
js/data.js      каталог, способы доставки, промокод (window.APP_DATA)
js/art.js       SVG-иллюстрации упаковок и аксессуаров
js/app.js       роутер, каталог, корзина, оформление, история
img/            фото CC0 (Openverse / rawpixel)
```

## Как редактировать данные

Всё в `js/data.js`:

- товар: объект в массиве `products`. Поля описаны в комментарии в начале файла. `id` становится адресом страницы товара.
- цена и фасовка: массив `variants` (`{ id, label, price }`).
- остаток: `stock` (число) или `null`, если без ограничений. Бейдж «Мало осталось» ставится полем `badges: ['low']`.
- цвет упаковки: поле `pack` ссылается на токен `--pack-*` в `css/style.css`. Для нового сорта добавьте токен и класс `.tone-*`.
- порог бесплатной доставки: `freeShippingFrom`, промокод: `promo`.

Цвета, отступы и шрифты меняются в блоке `:root` в начале `css/style.css`.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое папки `shop` в корень (или в отдельную папку).
2. В настройках репозитория: Settings -> Pages -> Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Маршруты работают через `#`, поэтому настройка сервера для SPA не нужна.
