# Траттория «Нонна Роза»

Многостраничный сайт семейной итальянской траттории в Москве. Концепт для портфолио: компания, цены и данные вымышлены, фото с лицензией CC0 (Openverse: rawpixel, StockSnap, WordPress Photo Directory).

Чистый HTML, CSS и JavaScript без сборки и зависимостей. Сайт открывается двойным кликом по `index.html`.

## Страницы и возможности

- **Главная** (`index.html`): первый экран с фото, история семьи, три фирменных блюда (одно крупнее), блок «Сегодня в печи» (блюдо дня меняется по дню недели), отзывы, часы работы с индикатором «Открыто сейчас / Закрыто, откроемся в ...». Время считается по Москве, независимо от часового пояса посетителя.
- **Меню** (`menu.html`): семь разделов, навигация по разделам залипает сверху и подсвечивает текущий раздел при прокрутке. Поиск по названию и составу с подсветкой совпадений, фильтры «Вегетарианское», «Острое», «Без глютена», «Хит», пустое состояние, аллергены и выход у каждого блюда. Кнопка «Печать меню» печатает чистое меню на A4 (всегда полное, даже если включены фильтры).
- **Бронь** (`booking.html`): 14 дней вперёд, понедельник до 16:00 санитарный день, 1-12 гостей (от 9 подсказка про банкетного менеджера), слоты с 12:00 до 22:30 каждые 30 минут (часть «занята» детерминированно), зоны «Зал», «Веранда» (только май-сентябрь), «У печи» (до 4 гостей), повод, имя, телефон с маской +7, пожелания. Итог справа на компьютере и снизу на телефоне. Брони сохраняются в браузере, их можно отменить с подтверждением.
- **О нас и контакты** (`about.html`): история, годы, команда (фото рук, без лиц), адрес, как добраться, часы, SVG-схема квартала и ссылка «Открыть в Яндекс Картах».

Светлая и тёмная тема («вечерний режим») переключаются автоматически по настройке системы.

## Структура

```
index.html, menu.html, booking.html, about.html
css/style.css        все стили: токены, светлая и тёмная тема, печать
js/icons.js          спрайт иконок Lucide
js/data.js           адрес, часы, блюда дня, фирменные блюда, правила брони
js/menu-data.js      меню (window.MENU), с инструкцией для владельца
js/config.js         ключ Web3Forms для отправки заявок
js/common.js         общая логика: мобильное меню, статус «Открыто», часы
js/home.js           главная
js/menu.js           меню: поиск, фильтры, подсветка раздела, печать
js/booking.js        бронирование
img/                 фотографии
```

## Как менять данные

- **Меню**: откройте `js/menu-data.js` в любом текстовом редакторе. Вверху файла пошаговая инструкция, как добавить, убрать блюдо или поменять цену.
- **Часы работы, блюдо дня, адрес, телефон, фирменные блюда, правила брони**: `js/data.js`. Адрес и телефон в шапке и подвале страниц написаны прямо в HTML, их нужно поменять поиском по всем четырём файлам.
- **Фото**: положите файл в `img/` и поменяйте путь в HTML или в `js/data.js`.

## Отправка заявок на бронь

По умолчанию форма работает в демо-режиме: бронь сохраняется только в браузере посетителя, после успеха показывается строка «Это демо-сайт, бронь сохранена только в вашем браузере».

Чтобы заявки приходили на почту:

1. Получите бесплатный ключ на https://web3forms.com (указывается почта, куда слать письма).
2. Вставьте его в `js/config.js`: `WEB3FORMS_KEY: 'ваш-ключ'`.

После этого форма отправляет POST-запрос на `https://api.web3forms.com/submit`. Если сервер недоступен, посетитель увидит сообщение с телефоном, а бронь не сохранится.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое папки `restaurant` (файлы `index.html` и остальные должны лежать в корне репозитория).
2. В репозитории откройте Settings, раздел Pages.
3. В поле Source выберите «Deploy from a branch», ветку `main` и папку `/ (root)`, нажмите Save.
4. Через минуту сайт будет доступен по адресу `https://<имя>.github.io/<репозиторий>/`.

## Доступность и качество

- WCAG 2.2 AA: контраст текста не ниже 4.5:1 в обеих темах, видимый фокус, пропуск к содержанию, всё управляется с клавиатуры.
- Выбор даты, времени, зоны и повода сделан на нативных радиокнопках (стрелки работают), подтверждение отмены брони на нативном `<dialog>` с возвратом фокуса.
- Отметки в меню передаются иконкой и подписью, не только цветом.
- `prefers-reduced-motion` отключает анимации, контент остаётся видимым.
- Все обращения к `localStorage` обёрнуты в try/catch: без хранилища сайт работает, просто не запоминает брони.
