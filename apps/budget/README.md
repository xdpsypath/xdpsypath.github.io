# Копилка: трекер личного бюджета (PWA)

Концепт для портфолио. Компания, цены и данные вымышлены, фото с лицензией CC0.

Копилка записывает траты и доходы с телефона за несколько касаний, показывает баланс месяца, сколько можно тратить в день до конца месяца, на что уходят деньги и как идут дела с лимитами по категориям. Работает офлайн, данные хранятся только на устройстве (IndexedDB).

Чтобы сразу увидеть приложение с данными, откройте `index.html?demo`: при пустом хранилище подставятся демо-записи за три месяца.

## Возможности

- **Обзор.** Баланс месяца крупно, доходы и расходы, «можно тратить в день» с учётом оставшихся дней, кольцевая диаграмма расходов по категориям (SVG, легенда со суммами и долями, клик по категории открывает её операции), график темпа расходов по сравнению с прошлым месяцем (подсказка по наведению и стрелками с клавиатуры, таблица-дубль), последние записи. Переключение месяцев.
- **Операции.** Список по дням с суммой за день, поиск по комментарию, категории и сумме, фильтр по типу и категории. Редактирование по нажатию на запись. Удаление кнопкой или свайпом влево, после удаления 5 секунд доступна кнопка «Отменить».
- **Добавление.** Нижняя шторка на телефоне и диалог на компьютере: Расход или Доход, крупная сумма, собственная цифровая клавиатура на телефоне и обычный ввод с клавиатуры на компьютере, категории чипами с иконками, дата (по умолчанию сегодня), комментарий. Последняя выбранная категория запоминается. Клавиша N открывает добавление.
- **Бюджеты.** Лимиты по категориям на месяц, общий остаток, полосы прогресса. От 80% лимита появляется предупреждение, при превышении сообщение «Превышен на ...»: состояние передаётся иконкой и текстом, а не только цветом.
- **Настройки.** Тема (Система, Светлая, Тёмная), валюта (₽, $, €, меняется только знак), показ копеек, установка приложения, экспорт и импорт JSON с проверкой формата и понятными ошибками, демо-данные, удаление всех данных с подтверждением словом «удалить».
- **PWA.** Манифест, иконки SVG и PNG 192/512 (плюс maskable и apple-touch-icon), service worker с версионированным кэшем, кнопка «Установить приложение» (появляется, только когда браузер разрешил установку), подсказка для iPhone, индикатор отсутствия сети.

## Офлайн и установка

Service worker регистрируется только при открытии по `http://` или `https://`. Если открыть `index.html` двойным кликом (адрес `file://`), приложение полностью работает, но офлайн-кэш и установка на экран «Домой» недоступны: так устроены браузеры. После публикации на GitHub Pages (или любом https-хостинге) первое открытие кэширует приложение, дальше оно запускается без сети.

Проверить локально: `py -m http.server 8000` в папке проекта и открыть `http://localhost:8000/`.

## Структура

```
index.html              разметка всех экранов, диалогов и спрайт иконок Lucide
css/style.css           токены (примитивы, семантика, тёмная тема) и компоненты
js/data.js              категории, валюты, правила демо-данных и демо-лимиты
js/db.js                обёртка хранилища: IndexedDB, запасной вариант localStorage, затем память
js/app.js               логика: экраны, диаграммы, формы, импорт/экспорт, PWA
sw.js                   service worker: precache оболочки, cache-first, кэш шрифтов
manifest.webmanifest    манифест приложения
icons/                  icon.svg, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png
```

## Как редактировать

- **Категории.** `js/data.js`, списки `categories.expense` и `categories.income`. Поле `icon` это id символа из спрайта в `index.html` (иконки Lucide; новую иконку добавьте туда же как `<symbol id="i-имя">`). Поле `slot` задаёт цвет на диаграмме (1-8, проверенная палитра), `0` означает серый цвет «Остальное».
- **Демо-данные и лимиты.** `js/data.js`, раздел `demo`: регулярные платежи, случайные траты с диапазоном сумм, лимиты в рублях.
- **Цвета, шрифты, отступы.** Только токены в начале `css/style.css`. Компоненты используют семантические токены, поэтому тема меняется в одном месте.
- **Новая версия.** После изменения файлов поменяйте `VERSION` в `sw.js`, иначе установленное приложение продолжит отдавать старый кэш. Новые файлы добавьте в список `SHELL`.

## Формат резервной копии

```json
{
  "app": "kopilka",
  "version": 1,
  "exportedAt": "2026-09-23T10:00:00.000Z",
  "settings": { "currency": "RUB", "theme": "system", "cents": false, "limits": { "cafe": 700000 } },
  "transactions": [
    { "id": "t1", "type": "expense", "amount": 45000, "category": "cafe", "date": "2026-09-23", "note": "Кофе", "createdAt": 1790000000000 }
  ]
}
```

Суммы хранятся в копейках (целые числа), даты в формате ГГГГ-ММ-ДД. Импорт заменяет текущие данные.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое папки (файл `index.html` в корне репозитория или в подпапке).
2. Settings, Pages, Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`. Пути в манифесте и service worker относительные (`./`), поэтому работают и в подпапке.

## Технологии

HTML, CSS и JavaScript без сборки и зависимостей. Шрифты Onest и Golos Text (Google Fonts, OFL), иконки Lucide (ISC). Палитра диаграмм проверена валидатором цветовой доступности (светлая и тёмная тема).
