# Лендинги для портфолио

Три концепт-лендинга на разные тематики. Каждый сайт самостоятельный: HTML, CSS и JavaScript без сборки и зависимостей. Компании, цены и отзывы вымышлены, об этом написано в подвале каждой страницы.

| Папка | Тематика | Стиль | Интерактив |
|---|---|---|---|
| `construction/` | «Опора», частные дома под ключ | Индустриальный: тёплый бетон, сигнальный оранжевый, острые углы, моноширинные подписи | Калькулятор стоимости дома, этапы стройки со сменой фото, форма записи на объект |
| `english-school/` | «Talkative», онлайн-школа разговорного английского | Дружелюбный: крем, фиолетовый и жёлтый, скруглённые формы, «тактильные» кнопки | Тест уровня из 5 вопросов, переключатель оплаты, форма пробного урока |
| `autosalon/` | «Графит», премиальные автомобили с пробегом | Кинематографичный тёмный: графит, кость, шампань | Каталог с фильтрами и сортировкой, карточка авто в модальном окне, кредитный калькулятор, запись на тест-драйв |

Строительство и школа автоматически переключаются в тёмную тему по настройке системы. Автосалон тёмный всегда: это часть образа бренда.

## Структура каждого сайта

```
index.html      разметка и тексты
css/style.css   токены (цвета, шрифты, отступы, анимации) и стили
js/main.js      интерактив
img/            фотографии
```

В начале `style.css` собраны все токены. Чтобы перекрасить сайт под другого клиента, достаточно поменять примитивы (например, `--signal-600` или `--violet-600`), остальное подтянется само.

## Как посмотреть

Откройте `index.html` любого сайта в браузере или поднимите локальный сервер:

```bash
npx serve landings
```

Для публикации подойдут GitHub Pages, Netlify или Vercel: каждая папка деплоится как статический сайт без сборки.

## Формы

Формы проверяют поля, показывают состояние загрузки и сообщение об успехе, но никуда не отправляют данные: это демо. Чтобы подключить реальную отправку, замените `setTimeout` в обработчике `submit` в `js/main.js` на запрос к вашему API, Formspree или боту в Telegram.

## Качество

Дизайн сделан по методике [ux-ui-agent-skills](https://github.com/plugin87/ux-ui-agent-skills): цвета и размеры только через токены, у каждого интерактивного элемента есть состояния hover, focus, active и disabled, есть поддержка `prefers-reduced-motion`, контраст соответствует WCAG AA, в интерфейсе нет эмодзи.

## Фотографии

Все фото взяты через [Openverse](https://openverse.org) с лицензией CC0 (Rawpixel и StockSnap): их можно использовать бесплатно, в том числе в коммерческих проектах, без указания автора. Марки автомобилей на фото принадлежат их владельцам. В демо они показаны как товар в каталоге, а не как бренд салона.
