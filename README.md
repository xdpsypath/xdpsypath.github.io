# Портфолио Дениса Шакирова

Сайты и веб-приложения, сделанные с помощью ИИ, с живыми демо. Всё статическое: HTML, CSS и JavaScript без сборки и зависимостей, работает на GitHub Pages без своего сервера.

Живая версия: https://xdpsypath.github.io/

## Работы

| Проект | Папка | Что показывает |
|---|---|---|
| Онлайн-запись в барбершоп «Сталь» | [`apps/barbershop`](apps/barbershop) | Пошаговая запись клиента и панель администратора с расписанием мастеров |
| Интернет-магазин кофе «Зерно и Пламя» | [`apps/shop`](apps/shop) | Каталог с фильтрами, корзина, промокод, оформление заказа в 4 шага |
| Дашборд сети кофеен «Утро» | [`apps/dashboard`](apps/dashboard) | Аналитика продаж на SVG-графиках, сравнение периодов, экспорт CSV |
| Трекер бюджета «Копилка» | [`apps/budget`](apps/budget) | PWA: установка на телефон, работа без интернета, IndexedDB |
| Траттория «Нонна Роза» | [`apps/restaurant`](apps/restaurant) | Многостраничный сайт: меню с поиском и фильтрами, бронь стола |
| Строительная компания «Опора» | [`landings/construction`](landings/construction) | Лендинг с калькулятором стоимости дома |
| Школа английского «Talkative» | [`landings/english-school`](landings/english-school) | Лендинг с тестом уровня и тарифами |
| Автосалон «Графит» | [`landings/autosalon`](landings/autosalon) | Лендинг с каталогом и кредитным калькулятором |

Компании, цены и данные во всех проектах вымышлены. Фотографии с лицензией CC0.

## Структура

```
index.html, css/, js/   главная страница-витрина
js/data.js              тексты витрины: имя, описание, работы, контакты
assets/previews/        превью работ для карточек
apps/                   веб-приложения
landings/               лендинги
```

У каждого проекта свой README: как устроен и как менять данные.

## Как обновить витрину

Тексты и список работ лежат в `js/data.js`. Пустые поля (`""` или `[]`) не показываются: например, чтобы добавить Telegram, впишите ссылку в `contacts.telegram`.

## Публикация

Репозиторий называется `xdpsypath.github.io`, поэтому GitHub Pages публикует его содержимое из ветки `main` по адресу https://xdpsypath.github.io/. Файл `.nojekyll` отключает обработку Jekyll, и файлы отдаются как есть.
